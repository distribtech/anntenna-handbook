# MCRP 8-10B.11 Antenna Handbook (Ukrainian)

Наданий файл MCRP-8-10B.11.pdf виглядає як скан без текстового шару. Засоби витягання тексту або OCR у цьому середовищі недоступні, оскільки через обмеження мережі неможливо встановити потрібні пакети (наприклад, `poppler-utils`, `PyPDF2` чи системи OCR). Тому повний переклад довідника у формат Markdown тут створити неможливо.

Щоб підготувати повноцінний український Markdown-файл, запустіть OCR або інший інструмент витягання тексту локально (наприклад, `ocrmypdf` чи `pdftotext`) і додайте отриманий Markdown у цю теку.
