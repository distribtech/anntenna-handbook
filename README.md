# Antenna Handbook (MCRP 8-10B.11)

This repository hosts a Markdown reconstruction of the USMC Antenna Handbook so it can be searched, translated, and published in multiple formats. Source PDFs (`MCRP-8-10B.11.pdf` and `marine_antena_merged.pdf`) live in the repository root. The `markdown/` directory contains the evolving transcription.

## Project layout
- `markdown/MCRP-8-10B.11/` — English transcription with per-section Markdown files.
- `markdown/MCRP-8-10B.11.uk/` — placeholder for additional language work.
- `MCRP-8-10B.11.pdf` — scanned source reference for the English edition.
- `marine_antena_merged.pdf` — supplemental reference pages.

## Building outputs
You can generate PDF and HTML outputs from the Markdown sources using [Pandoc](https://pandoc.org/). Install Pandoc locally, then run the commands below from the repository root.

### Build a single HTML handbook
```bash
pandoc markdown/MCRP-8-10B.11/foreword.md \
      markdown/MCRP-8-10B.11/chapter-1.md \
      -s -o build/antenna-handbook.html
```

### Build a single PDF handbook
```bash
pandoc markdown/MCRP-8-10B.11/foreword.md \
      markdown/MCRP-8-10B.11/chapter-1.md \
      -s -o build/antenna-handbook.pdf
```

> Create the `build/` directory first if it does not exist.

### Add images
Export figures from the source PDFs using tools like `pdftoppm` or `ocrmypdf` on a system with those utilities available. Save them in `markdown/MCRP-8-10B.11/images/` and reference them in the Markdown files with standard image syntax.

## Contributing
Please keep section numbering aligned with the printed handbook and cite the PDF pages you transcribe. Ensure newly added text is clear, concise, and consistent across both HTML and PDF outputs generated by Pandoc.
